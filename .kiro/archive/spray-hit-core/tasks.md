# Implementation Plan

各タスクはテストを先に書き、落ちることを確かめてから実装する。完了の根拠は Stop フック（EditMode）の終了コードと Test Runner の結果だけとする（tech.md 禁止事項 5）。
すべてのタスクは同じ2ファイル（噴射範囲の型とそのテストクラス）を触るため、並行実行（P）は付けない。
テストの起点には原点以外（例 (1, 1.5, -2)）も使い、起点を差し引き忘れる誤りを検出する。

- [x] 1. 噴射範囲の形を作れるようにする
- [x] 1.1 正しい値から噴射範囲を作り、値を読み出せるようにする
  - 起点・向き・半角・到達距離を受け取って噴射範囲を作る。値は生成後に変えられない
  - 起点・半角・到達距離は渡した値そのままを、向きは正規化した単位ベクトルを読み出せる
  - 半角・到達距離の既定値は持たない。半角 0.1° / 45° / 89.9°、到達距離 0.01m / 3m でも作れる
  - 完了条件: 「渡した値が読み出せる（起点 (1, 1.5, -2) を含む）」「向き (0,0,5) が (0,0,1) として読み出せる」「範囲内の任意の半角・到達距離で作れる」テストが EditMode で通る
  - _Requirements: 1.1, 1.2, 1.3, 1.4_

- [x] 1.2 壊れた形の噴射範囲を作れないようにする
  - 向きを単位ベクトルにできないとき（長さ 0、NaN、無限大）は向きが不正だと知らせる
  - 半角が 0° より大きく 90° より小さくないとき（NaN を含む）は半角が不正だと知らせる
  - 到達距離が 0m より大きくないとき（NaN を含む）は到達距離が不正だと知らせる
  - 検査の順は 向き → 半角 → 到達距離。知らせ方（例外の種類と引数名）は design.md「Error Categories and Responses」に従う
  - 完了条件: 向き (0,0,0) と (NaN,0,1)、半角 0 / -10 / 90 / 120 / NaN、到達距離 0 / -1 / NaN のそれぞれで、決められた例外と引数名が返るテストが EditMode で通る
  - _Requirements: 1.4, 3.1, 3.2, 3.3, 3.4_

- [x] 2. 命中を判定できるようにする
  - 起点からの距離が到達距離以下で、中心軸とのなす角が半角以下の位置を命中とする
  - 距離・角度の比較に design.md で決めた許容誤差（距離 1e-5m、cos 1e-6）を入れる。許容誤差は外に公開しない
  - 起点と同じ位置は、角度を求める前に命中とする（方向が決まらず 0 で割るため）
  - 判定は値を変えず、同じ位置なら何度呼んでも同じ結果を返す
  - 仮の初期値（半角 15°・到達距離 1.0m）で確かめ、起点が原点の場合と (1, 1.5, -2) の場合の両方で同じ結果になることを確かめる
  - このタスクの開始時点では判定がまだないので、追加したテストはまずコンパイルで落ちる。これをテストが先に書かれた証拠とする
  - 完了条件: 次のテストが EditMode で通る
    - 命中: 正面 0.5m、10°・0.5m、ちょうど 15°・0.5m、正面ちょうど 1.0m、ちょうど 15°・ちょうど 1.0m、起点そのもの
    - 外れ: 正面 1.001m、15.01°・0.5m、真横 0.5m、真後ろ 0.5m と 0.01m（許容誤差を入れても外れのまま）
    - 向き (0,0,5) で作った噴射範囲と (0,0,1) で作った噴射範囲が、同じ位置で同じ結果を返す
    - 同じ位置で2回判定しても結果が同じで、起点・向き・半角・到達距離が変わらない
  - _Requirements: 1.3, 2.1, 2.2, 2.3, 2.4, 2.5, 2.6, 2.7, 2.8_

- [x] 3. 規則が値によらず成り立つことを確かめ、テストの網羅を点検する
  - 半角 30°・到達距離 2.0m（起点 (1, 1.5, -2)）：25°・1.9m は命中、35°・1.0m と 正面 2.1m は外れ
  - 半角 5°・到達距離 0.3m：正面 0.29m は命中、6°・0.2m は外れ
  - 次の公開メンバーのそれぞれに少なくとも1本のテストがあることを確認する：生成、起点・向き・半角・到達距離の読み出し、命中の判定
  - 境界4ケースがテストで固定されていることを確認する：角度ちょうど（2.4）、距離ちょうど（2.5）、真後ろ（2.6）、起点と同じ位置（2.7）
  - 完了条件: 上の組のテストを含む全テストが、Stop フック（EditMode、シーンを開かない）で通る
  - _Requirements: 4.1, 4.2, 4.3, 4.4_
