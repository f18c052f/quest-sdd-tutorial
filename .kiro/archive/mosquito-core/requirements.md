# Requirements Document

依存する spec: なし

## Project Description (Input)
**誰が困っているか**：プレイヤー（と、規則を実装・テストする開発者）。蚊がいつ・どこに現れ、どう飛び、いつ「刺された」になるかの規則がないと、ゲームの判断軸（撃墜を狙うか、顔に近づけさせないか）が成立しない。外部設計では「放っておくと顔に近づく」「近くにとどまられると刺される」と文章で決まっているだけである。

**現状**：コードはない。人の表（learning-roadmap 3-2）では flight と spawn が別 spec だったが、難易度の変化を外すと spawn は小さすぎるため、1つにまとめた。

**何を変えるか**：時間を進めると、蚊の出現・位置・状態（飛行中／撃墜／刺した）が決まった規則で変わるようにする。蚊1匹の状態機械（顔へ近づく → 撃墜、または刺した）と、出現ルール（出現範囲の半径と高さ、同時数、間隔）を `MosquitoSpray.Core` に置く。時間は呼び出し側から経過秒数として渡し、Core は時計を持たない。乱数は差し替えられるようにし、テストでは固定する。刺された判定は、顔からの距離と、その範囲にいた秒数で決まる。規則はすべて EditMode テストで確かめられる。

**範囲**
- In：出現ルール（範囲・同時数・間隔）、飛行の状態遷移と速度、撃墜を受けたときの状態変化、刺された判定（距離×秒数）、刺したあとの蚊の扱い
- Out：蚊の見た目と落下の演出、噴射の命中判定そのもの（spray-hit-core）、スコアへの反映と減点の量（round-core）、難易度の選択・変化、外部設計にない飛び方（逃避など）、家具や壁との当たり判定（蚊は家具をすり抜ける）

**制約**
- `MosquitoSpray.Core` に置き、UnityEngine を参照しない
- 位置の型は spray-hit-core と揃える
- 蚊は手の届く範囲より外にも出るが、プレイヤーが追いかけなくて済む範囲にとどめる（外部設計 05 の安全）
- tasks が300行に近づいたら、刺された判定を別 spec に出すことを検討する

## Introduction
蚊の出現・飛行・撃墜・刺された判定の規則を、ゲーム画面やシミュレータを使わずにテストで確かめられる計算として定める。
時間は呼び出し側が経過秒数として渡し、顔の位置も呼び出し側がそのつど渡す。長さはメートル、時間は秒で扱う。

蚊1匹の状態は **接近中 → 撃墜** または **接近中 → 刺した** のどちらかで終わる。
brief にあった「漂う」段階は持たない。蚊は出現した直後から顔へ近づく。

刺された判定の秒数は、蚊1匹ごとに**累積**する。顔の近くの範囲から一度出ても 0 に戻さない。
しゃがむ・顔を振るといった動きでは刺されるのを遅らせられるだけで、防ぐには撃墜するしかない。

数値はすべて**仮の初期値**として次のとおりに置く。シミュレータで確かめながら調整する前提であり、規則はどの正しい値に対しても成り立つようにする。
値を調整したときは、コードより先に design.md を直す。

| 値 | 仮の初期値 |
| --- | --- |
| 刺された判定の距離（顔の位置から） | 0.3m |
| 刺された判定の秒数（累積） | 2.0秒 |
| 出現範囲の水平距離（顔の位置から） | 1.0m 以上 2.0m 以下 |
| 出現範囲の高さ（顔の高さから） | -0.5m 以上 +0.5m 以下 |
| 同時数の上限 | 3匹 |
| 出現間隔 | 2.0秒 |
| 接近の速さ | 0.5m/s |

## Boundary Context
- **In scope**: 出現の開始と停止、出現の位置・同時数・間隔、蚊が顔へ近づく動き、命中を知らされたときの撃墜、刺された判定（距離と累積秒数）、刺したあとに蚊が消えること、各蚊の位置と状態を読み出せること、設定値と経過秒数の検査
- **Out of scope**: 噴射範囲に蚊が入ったかの判定（spray-hit-core。この spec は「命中した」という知らせを受け取るだけ）、撃墜・刺されたことをスコアに反映することと減点の量（round-core）、蚊の見た目・落下の動き・刺されたときの演出（mosquito-view-adapter / round-hud-adapter）、家具や壁との当たり判定、逃避などの外部設計にない飛び方、難易度の選択とラウンド中の変化、設定値を保持・調整する仕組み
- **Adjacent expectations**:
  - 呼び出し側（mosquito-view-adapter / round-flow-adapter）は、ラウンドの開始・終了に合わせて出現の開始・停止を指示し、プレイ中は経過秒数と現在の顔の位置を渡し続ける
  - 呼び出し側は、蚊の位置を spray-hit-core の噴射範囲と同じ座標空間で受け取り、命中と判定した蚊をこの spec に知らせる
  - 撃墜・刺されたことは呼び出し側が読み取り、スコアへの反映は round-core 側が行う。この spec は round-core を直接参照しない

## Requirements

### Requirement 1: 出現の開始と停止
**Objective:** プレイヤーとして、ラウンド中だけ蚊が現れてほしい。待機中や結果表示中に蚊が飛んでいないようにするためである。

#### Acceptance Criteria
1. While 出現が開始されていないとき, the Mosquito Core shall 時間が進められても蚊を出現させない
2. When 出現を開始したあと最初に時間が進められたとき, the Mosquito Core shall 蚊を1匹出現させる
3. When 出現を停止したとき, the Mosquito Core shall その時点のすべての蚊を取り除き、以後は再び開始されるまで蚊を出現させない
4. When 停止したあとに出現を再び開始したとき, the Mosquito Core shall 前回の蚊や経過秒数を引き継がず、最初に開始したときと同じ規則で出現させる

### Requirement 2: 出現の位置
**Objective:** プレイヤーとして、蚊は手の届く少し先に現れてほしい。追いかけて歩き回る必要がなく、かといって目の前に突然現れないようにするためである。

#### Acceptance Criteria
1. When 蚊を出現させるとき, the Mosquito Core shall その時点の顔の位置からの水平距離が出現範囲の内側の距離以上・外側の距離以下となる位置に出現させる
2. When 蚊を出現させるとき, the Mosquito Core shall その時点の顔の高さとの差が出現範囲の高さの下限以上・上限以下となる位置に出現させる
3. The Mosquito Core shall 出現範囲の中のどこに出現させるかを、差し替えられる乱数によって決める
4. When 同じ乱数の並びと同じ入力の列が与えられたとき, the Mosquito Core shall 毎回同じ位置に同じ順番で蚊を出現させる

### Requirement 3: 同時数と出現間隔
**Objective:** プレイヤーとして、蚊が一定の間隔で現れ、多すぎない数が同時に飛んでいてほしい。1ラウンドの間、狙う相手が途切れず、かつ手に負える数に収まるようにするためである。

#### Acceptance Criteria
1. While 接近中の蚊の数が同時数の上限未満で、かつ直前の出現から出現間隔以上の秒数が経っているとき, the Mosquito Core shall 時間が進められたときに蚊を1匹出現させる
2. While 接近中の蚊の数が同時数の上限に達しているとき, the Mosquito Core shall 出現間隔が過ぎても蚊を出現させない
3. When 蚊が撃墜されたか刺して消えたことで接近中の蚊の数が上限未満になり、直前の出現から出現間隔以上が経っているとき, the Mosquito Core shall 次に時間が進められたときに蚊を1匹出現させる
4. When 1回の時間経過が出現間隔の複数倍にわたるとき, the Mosquito Core shall 経過した出現間隔の数だけ蚊を出現させ、接近中の蚊の数が同時数の上限を超えないようにする
5. The Mosquito Core shall 撃墜された蚊と刺して消えた蚊を、同時数に数えない

### Requirement 4: 顔への接近
**Objective:** プレイヤーとして、放っておいた蚊は顔に近づいてきてほしい。撃墜を狙うか顔に近づけさせないかの判断が生まれるようにするためである。

#### Acceptance Criteria
1. When 時間が進められたとき, the Mosquito Core shall 接近中のすべての蚊を、その時点の顔の位置へ向かってまっすぐ、接近の速さ×経過秒数の距離だけ動かす
2. If その時間経過で動く距離が顔の位置までの距離より大きいとき, the Mosquito Core shall 蚊を顔の位置で止め、顔の位置を通り過ぎさせない
3. When 顔の位置が前回と変わったとき, the Mosquito Core shall 新しい顔の位置へ向かって蚊を動かす
4. When 経過秒数 0 で時間が進められたとき, the Mosquito Core shall 蚊の位置も状態も変えない
5. The Mosquito Core shall 蚊の動きを家具や壁でさえぎらない

### Requirement 5: 撃墜
**Objective:** プレイヤーとして、命中した蚊はその場で撃墜されてほしい。撃墜した蚊に刺されたり、同じ蚊が二度数えられたりしないようにするためである。

#### Acceptance Criteria
1. When 接近中の蚊について命中が知らされたとき, the Mosquito Core shall その蚊を撃墜の状態にし、撃墜されたことを呼び出し側が読み取れるようにする
2. While 蚊が撃墜の状態のとき, the Mosquito Core shall その蚊を動かさず、刺された判定の秒数も加えない
3. If 撃墜された蚊、刺して消えた蚊、または存在しない蚊について命中が知らされたとき, the Mosquito Core shall 状態を変えず、撃墜を新たに起こさない
4. When 撃墜したとき, the Mosquito Core shall その蚊の撃墜された位置を呼び出し側が読み取れるようにする

### Requirement 6: 刺された判定
**Objective:** プレイヤーとして、蚊に顔の近くにいられた時間が一定に達したら刺されてほしい。顔を振ってごまかすのではなく、撃墜することでしか防げないようにするためである。

#### Acceptance Criteria
1. When 時間が進められ、その時間経過のあとで接近中の蚊と顔の位置との距離が刺された判定の距離以下のとき, the Mosquito Core shall その経過秒数をその蚊の累積秒数に加える
2. When 時間が進められ、その時間経過のあとで蚊と顔の位置との距離が刺された判定の距離より大きいとき, the Mosquito Core shall その蚊の累積秒数を増やさず、0 にも戻さない
3. When 蚊の累積秒数が刺された判定の秒数以上になったとき, the Mosquito Core shall その蚊を刺した状態にし、刺されたことを呼び出し側が読み取れるようにする
4. When 蚊と顔の位置との距離がちょうど刺された判定の距離のとき, the Mosquito Core shall 範囲内として秒数を加える
5. The Mosquito Core shall 累積秒数を蚊1匹ごとに別々に数え、ほかの蚊の秒数と合算しない

### Requirement 7: 刺したあとの蚊
**Objective:** プレイヤーとして、刺した蚊はいなくなってほしい。1匹の蚊に何度も刺されず、次の蚊が現れるようにするためである。

#### Acceptance Criteria
1. When 蚊が刺した状態になったとき, the Mosquito Core shall その蚊を以後動かさず、命中の対象にも刺された判定の対象にもしない
2. The Mosquito Core shall 1匹の蚊について、刺されたことを1回だけ起こす
3. When 同じ時間経過で複数の蚊が刺した状態になったとき, the Mosquito Core shall 刺された回数をその蚊の数だけ呼び出し側が読み取れるようにする

### Requirement 8: 状態の読み出し
**Objective:** 開発者として、各蚊の位置と状態、その時間経過で起きたことを読み出したい。見た目への反映とスコアへの受け渡しを、蚊の規則を知らずに行えるようにするためである。

#### Acceptance Criteria
1. The Mosquito Core shall 存在する各蚊について、蚊を区別する識別子・現在の位置・状態（接近中・撃墜・刺した）を呼び出し側が読み取れるようにする
2. When 時間が進められたとき, the Mosquito Core shall その時間経過で新たに出現した蚊と、新たに刺した状態になった蚊を呼び出し側が読み取れるようにする
3. When 撃墜したとき, the Mosquito Core shall 撃墜された蚊を呼び出し側が読み取れるようにする
4. The Mosquito Core shall 同じ蚊の識別子を、その蚊が存在する間は変えず、ほかの蚊に使い回さない

### Requirement 9: 不正な値の拒否
**Objective:** 開発者として、壊れた設定値や経過秒数は受け付けないようにしたい。設定の入れ間違いやバグに、「蚊が出ない」「刺されない」という症状ではなくその場で気づけるようにするためである。

#### Acceptance Criteria
1. If 刺された判定の距離、刺された判定の秒数、出現間隔、接近の速さのいずれかが 0 以下のとき, the Mosquito Core shall 設定を受け付けず、どの値が不正かを呼び出し側に知らせる
2. If 出現範囲の内側の水平距離が 0 より小さいか、外側の水平距離が内側の水平距離より小さいとき, the Mosquito Core shall 設定を受け付けず、出現範囲が不正であることを呼び出し側に知らせる
3. If 出現範囲の高さの下限が上限より大きいとき, the Mosquito Core shall 設定を受け付けず、出現範囲が不正であることを呼び出し側に知らせる
4. If 同時数の上限が 1 より小さいとき, the Mosquito Core shall 設定を受け付けず、同時数が不正であることを呼び出し側に知らせる
5. If 時間を進めるときの経過秒数が 0 より小さいとき, the Mosquito Core shall 蚊の位置も状態も変えず、経過秒数が不正であることを呼び出し側に知らせる

### Requirement 10: テストで確かめられること
**Objective:** 開発者として、蚊の規則をゲームやシミュレータを起動せずに確かめたい。見た目から推測せず、テストの結果で規則が正しいと判断できるようにするためである。

#### Acceptance Criteria
1. The Mosquito Core shall ゲームのシーンや実行環境を起動しない自動テストだけで、Requirement 1〜9 のすべての規則を確かめられるようにする
2. The Mosquito Core shall 外部に公開するすべての操作について、少なくとも1つの自動テストを持つ
3. The Mosquito Core shall 乱数を固定した自動テストで、出現の位置と順番を確かめられるようにする
4. The Mosquito Core shall 距離ちょうど・累積秒数ちょうど・顔の位置を通り過ぎる移動・範囲を出入りしたあとの累積の4つについて、期待する結果を自動テストで固定する
5. The Mosquito Core shall 仮の初期値とは異なる値の組み合わせでも、規則が成り立つことを自動テストで確かめる
