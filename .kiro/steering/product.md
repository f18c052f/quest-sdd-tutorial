# product — このプロジェクトの前提

## 目的

このリポジトリは **「Quest MRアプリ 仕様駆動開発ガイドライン」を一人で1周して、守りにくい箇所を
見つけるための学習用リポジトリ**である。ゲームの完成度は目的ではない。

判断に迷ったら「ゲームとして良くなるか」ではなく「ガイドラインの流れを正しくなぞれているか」で選ぶ。
ガイドラインに従った結果うまくいかなかったことは、失敗ではなく成果として記録する。

## 作るもの

パススルーで見える自分の部屋に飛ぶ蚊を、スプレーで撃退するミックスリアリティのゲーム。

- 自分の部屋が見えている（パススルー）。その空間を蚊が飛び回る
- 右手コントローラーのトリガーでスプレーを噴射する
- 噴射範囲に入った蚊は落ちる
- 制限時間内に落とした数を競う
- 蚊が顔の近くに一定時間とどまると「刺された」になり、減点される

## プレイヤー

| 項目 | 前提 |
| --- | --- |
| 機材 | Meta Quest 3 系。コントローラーを両手に持つ |
| 場所 | 自宅の部屋。家具がある |
| 姿勢 | 座位と立位のどちらでも成立させる。歩き回ることは前提にしない |
| 入力 | 右手コントローラーのトリガーのみ。ハンドトラッキングは使わない |
| 1回の長さ | 数分。連続プレイは前提にしない |

## 用語集

仕様・コード・spec 名で同じものを指すときは、必ずこの語を使う。
外部設計（`docs/external/`）の用語もこれに揃える。

| 日本語 | コード上の語 | 意味 |
| --- | --- | --- |
| 蚊 | Mosquito | 撃退の対象。空中を飛ぶ |
| スプレー | Spray | プレイヤーが持つ道具 |
| 噴射 | Emit | トリガーを引いてスプレーを出す行為 |
| 噴射範囲 | SprayVolume | 噴射が届く空間。これに入った蚊が命中になる |
| 命中 | Hit | 蚊が噴射範囲に入り、撃墜が確定すること |
| 撃墜 | Downed | 命中した蚊が落ちること |
| 刺された | Bitten | 蚊が顔の近くに一定時間とどまり、減点されること |
| ラウンド | Round | 制限時間つきの1回のプレイ。待機 → プレイ → 終了 |
| スコア | Score | ラウンド中の得点 |
| 出現 | Spawn | 蚊が空間に現れること |

「撃退」「倒す」「やっつける」は会話では使ってよいが、仕様とコードでは **撃墜（Downed）** に統一する。

## この学習で体験しないこと

ロードマップ 3-0 で対象外と決めたもの。ガイドラインに書かれていても、このリポジトリでは扱わない。
足りないと感じても、ここでルールを足さない。

| ガイドラインの項目 | ここでの扱い |
| --- | --- |
| Work Item、仕様PR・実装PR | ローカルのブランチとコミットで代替する |
| 他者レビュー、並列度、シーン所有者 | 一人なので体験しない。自分で読み返す |
| CI、ブランチポリシー | 体験しない。品質ゲートは Stop フックまで |
| 顧客承認 | 体験しない。外部設計を自分で書くところまで |
| 実機検証 | 体験しない。Meta XR Simulator で代替する |

GitHub は保存先としてのみ使う。Issue・Pull Request・GitHub Actions は使わない。
