# Requirements Document

依存する spec: なし

## Project Description (Input)
**誰が困っているか**: 蚊を噴射で撃墜するプレイヤーと、その命中規則をテストで確かめたい開発者。

**現状**: `MosquitoSpray.Core` の asmdef があるだけでコードはなく、命中の規則は外部設計に文章で書かれているだけ（「噴射はコントローラーの向いた先に出る」「手を伸ばした先の届く範囲にしか当たらない」）。判定が GameObject や物理演算に埋もれると、テストで確かめられず、シミュレータで見た目から推測するしかなくなる。

**何を変えるか**: 噴射範囲（SprayVolume）を、起点から向きの方向に伸びる円錐（半角と到達距離で形が決まる）として表し、噴射の起点・向き・噴射範囲の形と蚊の位置を渡すと命中かどうかが返るようにする。`MosquitoSpray.Core` に置き UnityEngine を参照しない（単位はメートルと度）。すべての public メソッドに EditMode テストがあり、境界値（角度ちょうど、距離ちょうど、真後ろ、起点と同じ位置）がテストで決まっている。

範囲外: 噴射の入力（トリガー・連射）、噴射の見た目、命中した蚊の状態変更、Unity の Collider / Physics による当たり判定。

## Introduction
噴射が蚊に当たったかどうかを決める規則を、ゲーム画面やシミュレータを使わずにテストで確かめられる計算として定める。
噴射範囲は「起点から向きの方向に伸びる円錐」で、形は半角（中心軸から縁までの角度）と到達距離（起点からの距離）で決まる。
長さはメートル、角度は度で扱う。

半角と到達距離は**仮の初期値として 半角 15°・到達距離 1.0m** を置く。
この値はシミュレータで実際に確かめながら調整する前提であり、命中の規則はどんな正しい値に対しても成り立つようにする。
値を調整したときは、コードより先に design.md を直す。

## Boundary Context
- **In scope**: 噴射範囲の形（起点・向き・半角・到達距離）を表すこと、形が正しいかを確かめること、ある位置が噴射範囲に入るか（命中か）を判定すること
- **Out of scope**: 噴射を出すタイミングと連射の扱い（spray-input-adapter）、噴射の見た目、命中した蚊を撃墜状態にすること（mosquito-core / mosquito-view-adapter）、物理演算や当たり判定用の形状を使った判定、半角・到達距離の値を設定として保持・調整する仕組み
- **Adjacent expectations**:
  - 呼び出し側（spray-input-adapter）は、コントローラーの位置と向きを噴射範囲の起点と向きとして渡す。姿勢が取れないときは噴射範囲を作らずに済ませる
  - 呼び出し側（mosquito-view-adapter）は、蚊の位置を噴射範囲と同じ座標空間で渡す。命中と判定されたあとの扱いは呼び出し側が決める

## Requirements

### Requirement 1: 噴射範囲の形
**Objective:** 開発者として、噴射範囲の形を起点・向き・半角・到達距離で表したい。命中の規則を一つの形に対して確かめられるようにするためである。

#### Acceptance Criteria
1. When 起点・向き・半角・到達距離として正しい値が与えられたとき, the Spray Hit Core shall その値を持つ噴射範囲を作る
2. The Spray Hit Core shall 作った噴射範囲から、与えられた起点・半角・到達距離と同じ値を読み出せるようにする
3. When 向きとして長さが 1 でない値が与えられたとき, the Spray Hit Core shall 向きの長さを無視し、その方向だけを噴射範囲の中心軸として使う
4. The Spray Hit Core shall 半角と到達距離を固定値として持たず、0° より大きく 90° より小さい任意の半角と、0m より大きい任意の到達距離を受け付ける

### Requirement 2: 命中の判定
**Objective:** プレイヤーとして、コントローラーを向けた先の届く範囲にいる蚊にだけ噴射が当たってほしい。狙った蚊が落ち、部屋の反対側の蚊には当たらないようにするためである。

#### Acceptance Criteria
1. When 噴射範囲と蚊の位置が与えられ、起点から蚊までの距離が到達距離以下で、かつ中心軸と起点から蚊への方向とのなす角が半角以下のとき, the Spray Hit Core shall 命中と判定する
2. When 起点から蚊までの距離が到達距離より大きいとき, the Spray Hit Core shall 命中しないと判定する
3. When 中心軸と起点から蚊への方向とのなす角が半角より大きいとき, the Spray Hit Core shall 命中しないと判定する
4. When 中心軸と起点から蚊への方向とのなす角がちょうど半角で、距離が到達距離以下のとき, the Spray Hit Core shall 命中と判定する
5. When 起点から蚊までの距離がちょうど到達距離で、なす角が半角以下のとき, the Spray Hit Core shall 命中と判定する
6. When 蚊が起点から見て向きの真後ろ（なす角 180°）にいるとき, the Spray Hit Core shall 距離にかかわらず命中しないと判定する
7. When 蚊の位置が起点とまったく同じとき, the Spray Hit Core shall 命中と判定する
8. When 同じ噴射範囲と同じ蚊の位置で判定を繰り返したとき, the Spray Hit Core shall 毎回同じ結果を返し、噴射範囲の値を変えない

### Requirement 3: 壊れた形の拒否
**Objective:** 開発者として、壊れた形の噴射範囲は作れないようにしたい。設定値の入れ間違いやバグに、「なぜか当たらない」という症状ではなくその場で気づけるようにするためである。

#### Acceptance Criteria
1. If 向きの長さが 0 のとき, the Spray Hit Core shall 噴射範囲を作らず、向きが不正であることを呼び出し側に知らせる
2. If 半角が 0° 以下のとき, the Spray Hit Core shall 噴射範囲を作らず、半角が不正であることを呼び出し側に知らせる
3. If 半角が 90° 以上のとき, the Spray Hit Core shall 噴射範囲を作らず、半角が不正であることを呼び出し側に知らせる
4. If 到達距離が 0m 以下のとき, the Spray Hit Core shall 噴射範囲を作らず、到達距離が不正であることを呼び出し側に知らせる

### Requirement 4: テストで確かめられること
**Objective:** 開発者として、命中の規則をゲームやシミュレータを起動せずに確かめたい。見た目から推測せず、テストの結果で規則が正しいと判断できるようにするためである。

#### Acceptance Criteria
1. The Spray Hit Core shall ゲームのシーンや実行環境を起動しない自動テストだけで、Requirement 1〜3 のすべての判定を確かめられるようにする
2. The Spray Hit Core shall 外部に公開するすべての操作について、少なくとも1つの自動テストを持つ
3. The Spray Hit Core shall 角度ちょうど・距離ちょうど・真後ろ・起点と同じ位置の4つの境界について、期待する結果を自動テストで固定する
4. The Spray Hit Core shall 仮の初期値（半角 15°・到達距離 1.0m）とは異なる半角・到達距離の組み合わせでも、命中の規則が成り立つことを自動テストで確かめる
